# Portafolio

A small static personal portfolio for side projects built with native web technologies.

The landing page is a three.js voxel diorama of life in Tulum (a ceiba tree with palm fronds, birds, a cenote and an off-grid house). It lives in `scene.js`; tweak it through the `CONFIG` object at the top of that file.

Run it locally with any static server, e.g. `python3 -m http.server 8000`.
